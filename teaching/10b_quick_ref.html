Antiderivatives and Indefinite Integrals

In math 10A, most of the focus was placed on computing the derivative of functions. In math 10B, the focus is entirely on undoing this process.
Definition. We say \(F(x)\) is an antiderivative of a function \(f\) if \[ F'(x) = f(x). \]
Note that \((F(x)+2)' = F'(x) = f(x)\) so antiderivatives of \(f(x)\) are not unique. In fact, \(F(x)+C\) is an antiderivative of \(f(x)\) for any constant \(C\). By the Mean Value Theorem, we know that if \(g'(x)=f'(x)\) for all \(x\) in some interval then \(f(x)=g(x)+C\) for some constant \(C\). Therefore, if we find one antiderivative of \(f(x)\), say \(F(x)\), then \(F(x)+C\) (as \(C\) varies) are all the antiderivatives of \(f(x)\).
Definition. The indefinite integral of \(f(x)\) is all possible antiderivatives of \(f(x)\) which we denote by \[ \int f(x)dx. \] From the discussion above, if \(F'(x)=f(x)\) is an antiderivative then the indefinite integral of \(f(x)\) is given by \[ \int f(x)dx = F(x) + C. \]
Let's look at some examples, try them yourself first!
Example. Determine whether the following functions are antiderivatives of the given functions:
  1. \(F(x)=(x+2)^2\) and \(f(x)=2x+4\)
  2. \(G(x)=x^2+3x+1\) and \(g(x)=2x+4\)
  3. \(H(x)=\sin(3x) + 5\) and \(h(x)=3\cos x\)
Show Solution.
  1. Note that \[ F'(x) = \frac{d}{dx}(x+2)^2 = 2(x+2) = 2x+4 = f(x) \] so \(F(x)\) is an antiderivative of \(f(x)\).
  2. Note that \[ G'(x) = \frac{d}{dx}(x^2 + 3x + 1) = 2x + 3 \neq 2x+4 = g(x) \] so \(G(x)\) is not an antiderivative of \(g(x)\).
  3. Note that \[ H'(x) = \frac{d}{dx}(\sin(3x)+5) = 3\cos(3x) \neq 3\cos x = h(x) \] so \(H(x)\) is not an antiderivative of \(h(x)\).

Basic Examples

We know a few derivative rules that we can easily rephrase in terms of an indefinite integral. Namely, we know that
  • \( \displaystyle \frac{d}{dx}\sin x = \cos x \)
  • \( \displaystyle \frac{d}{dx}\cos x = - \sin x \)
  • \( \displaystyle \frac{d}{dx}\tan x = (\sec x)^2 \)
  • \( \displaystyle \frac{d}{dx} \ln |x| = \frac{1}{x} \)
  • \( \displaystyle \frac{d}{dx} e^x = e^x \)
  • \( \displaystyle \frac{d}{dx} \left( \frac{x^{n+1}}{n+1} \right) = x^n \;\; \) when \(n\neq -1\).
These statements become:
Some Indefinite Integrals.
  • \( \displaystyle \int \cos xdx = \sin x + C \)
  • \( \displaystyle \int \sin xdx = -\cos x + C \)
  • \( \displaystyle \int (\sec x)^2dx = \tan x + C \)
  • \( \displaystyle \int \frac{1}{x}dx = \ln|x| + C \)
  • \( \displaystyle \int e^xdx = e^x + C \)
  • \( \displaystyle \int x^n = \frac{x^{n+1}}{n+1} + C \;\; \) when \(n \neq -1\).
We can use the above and the following result to compute some more complicated indefinite integrals.
Linearity of Indefinite Integral. For functions \(f(x),g(x)\) and real numbers \(a,b\), \[ \int (af(x)+bg(x))dx = a\int f(x)dx + b\int g(x)dx. \]
Let's do some examples, try them for yourself first!
Examples. Evaluate the following indefinite integrals:
  1. \( \displaystyle \int x^3 + \pi x^2 dx \)
  2. \( \displaystyle \int 9\sin x + 4e^x dx \)
  3. \( \displaystyle \int \frac{2t^2+t^{3/2}}{3\sqrt{t}}dt \)
Show Solution.
  1. Note that \[ \begin{align*} \int x^3 + \pi x^2 dx &= \int x^3 dx + \pi\int x^2 dx && \text{[by linearity]} \\ &= \boxed{\frac{x^4}{4} + \pi \frac{x^3}{3} + C} && \text{[by antipower rule]} \end{align*} \]
  2. Note that \[ \begin{align*} \int 9\sin x + 4e^x dx &= 9\int \sin xdx + 4 \int e^x dx && \text{[by linearity]} \\ &= \boxed{-9\cos x + 4e^x + C} && \text{[by our known integrals]} \end{align*} \]
  3. We first begin by simplifying the integrand: \[ \begin{align*} \int \frac{2t^2+t^{3/2}}{3\sqrt{t}}dt &= \frac{1}{3} \left( \int \frac{2t^2}{t^{1/2}} dt + \int \frac{t^{3/2}}{t^{1/2}}dt \right) && \text{[by linearity]} \\ &= \frac{1}{3} \left(2\int t^{3/2}dt + \int t^1 dt \right) \\ &= \frac{1}{3} \left( 2 \frac{t^{5/2}}{5/2} + \frac{t^2}{2} \right) + C && \text{[by the antipower rule]} \\ &= \boxed{\frac{1}{3} \left( \frac{4t^{5/2}}{5} + \frac{t^2}{2} \right) + C} \end{align*} \]

Initial Value Problems

So far, when integrating, we've been getting families of functions as our \(C\), the constant of integration, can be any real number. However, if we're given an initial value of our function then we can actually solve for our constant of integration exactly.
Example. Let \(f(x)\) be a function such that \(f(1)=0\) and \[ f'(x) = 3x^2 + e^x. \] Find \(f(x)\).
Show Solution.

Note that (upto a constant) \[ f(x) = \int f'(x)dx = \int 3x^2 + e^x dx = x^3 + e^x + C. \] Now, using the fact that \(f(1)=0\), we see that \[ 0 = f(1) = 1^3 + e^1 + C = 1 + e + C \Longrightarrow C = -(1+e). \] Thus, we conclude that \[ \boxed{f(x) = x^3 + e^x - (1+e).} \]
